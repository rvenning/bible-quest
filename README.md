# Bible Quest 📖

A Bible-story trivia adventure for the whole family. Journey through **17 great
Bible stories in order** — from Creation and Noah's Ark all the way to Easter and
Paul's journeys — answering fun multiple-choice questions along the way. Pass a
story to unlock the next one, earn stars and coins, and climb the family
leaderboard. Written for ages 6–12: well-known stories, people, places and
numbers, all kid-appropriate.

**Play it:** https://rvenning.github.io/bible-quest/

## Features
- 🗺️ **Story level map** — 17 Bible stories in narrative order, unlocking in
  sequence as you complete them
- ❓ **Multiple-choice trivia** — 4 options per question, ~10 questions per story,
  difficulty ramping up within each round
- ⭐ **Stars & coins** — 1–3 stars per story (6/10 to pass, perfect 10/10 for
  three), coins for every correct answer, bigger rewards on a hot streak
- 🔥 **Streaks & instant feedback** — the right answer lights up green, a gentle
  sound on a miss, then auto-advance to the next question
- 🎉 **Celebrations** — confetti and a fanfare on a passed level, a sparkle
  jingle for a perfect round
- 🤗 **Kind, not harsh** — miss the pass mark and it's a friendly "so close — try
  again!", never a GAME OVER
- 👨‍👩‍👧 Pick-a-name family profiles — no passwords; optional 4-digit PIN per
  profile with an admin override
- 🏆 Shared family leaderboard — total score, stars and stories completed across
  all players
- 🔊 All sound effects synthesized with WebAudio (no asset downloads)
- ☁️ Firebase Firestore sync (falls back to localStorage offline)
- 📱 iPad-first: big touch targets; works with a mouse on desktop
- 📲 Installable PWA: "Add to Home Screen" button, offline play via service worker

## Scoring
- **+100** points per correct answer, **+20** more for each step of the current
  streak
- **+5** coins per correct answer, **+2** extra while a streak is going
- **Stars per story:** 6–7 correct = ⭐, 8–9 = ⭐⭐, 10/10 = ⭐⭐⭐
- **Pass mark:** 6 of 10 correct completes the story and unlocks the next one
- Progress `{ coins, levels, updated }` reconciles across devices by keeping the
  **best score per level** and the max coins, so playing on the iPad and a phone
  never loses your stars.

## Built on gamekit
Profiles, PINs, storage/sync, the sound engine, base UI styles and the PWA kit come from
[rvenning/gamekit](https://github.com/rvenning/gamekit), vendored into `lib/`.
To pull in a newer kit version:

```powershell
# from the gamekit repo
node tools/sync-to-game.js "D:\OneDrive\Documents\Claude Code\bible-quest"
# then test, bump the CACHE version in sw.js, and commit
```

Everything game-specific — the question bank, the round engine, the level map, the
jingles — lives in `js/` (loaded as plain browser scripts, no build step).

## PWA files
- `manifest.json` — app identity: name, icons, standalone display, theme colours
- `sw.js` — service worker; precaches the app shell (including `lib/`), then network-first with cache fallback
- `icons/` — 192/512 PNG app icons plus a maskable variant, generated by `tools/make-icons.js` (no image tools needed — pure Node)

## Local development
No build step — plain HTML/JS. Serve the folder with any static server:

```powershell
npx http-server . -p 8099 -c-1   # http://localhost:8099
```

Regenerate the icons after changing the art:

```powershell
node tools/make-icons.js
```

Run the question-bank tests (a data linter — checks every level has enough
questions, 4 unique options each, no duplicate answers):

```powershell
node --test
```

Deploys are just pushes to `main` (GitHub Pages).

## Storage
Progress lives in `localStorage` (keys `bq_*`) and mirrors to Cloud Firestore
(collection `biblequest`, same Firebase project as WordVoyage, Chicken Cross and
Block Party). The Firebase API key in `js/firebase-config.js` is public by design —
it only identifies the project; access is limited by Firestore security rules, and
the key is referrer-restricted to the game's domains and locked to the Firestore API.
